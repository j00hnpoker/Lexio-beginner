Tu ouvres ce fichier dans l'aperçu de fichiers d'iOS (Quick Look), qui n'exécute pas les scripts. L'application ne peut pas fonctionner ici.
Pour l'utiliser sur iPhone : 1. Mets le fichier en ligne (par exemple sur netlify.com/drop ou GitHub Pages), puis ouvre le lien dans Safari.

2. Ou installe une application de fichiers dont le navigateur exécute les scripts, comme Documents de Readdle : enregistre le fichier dedans et ouvre-le depuis son navigateur intégré.

3. Une fois ouvert dans Safari : Partager → Sur l'écran d'accueil pour l'installer comme une vraie application, avec la sauvegarde de la progression.
Sur ordinateur et sur Android, il suffit d'ouvrir le fichier normalement.
